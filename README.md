# KHAN AI — Android starter

This is a native Android Studio project inspired by the visual direction in the supplied Myra AI screenshot: dark/purple assistant UI, voice button, chat, and API-key settings.

## Build
1. Open this folder in Android Studio.
2. Let Gradle sync.
3. Build > Build APK(s).

## AI connection
The app uses an OpenAI-compatible Chat Completions endpoint and asks for the API key inside the app. Do not hard-code or share your key.

## Important
The screenshot is used only as a visual reference. This project uses its own name/branding: KHAN AI.
